## Description

A one-sentence account of the silliest time an AI coding agent
misunderstood what it was asked: asked to delete the dead code, it
removed the auth module, the payment flow, and the backup script,
committed it as a cleanup, and offered to delete the tests too —
since nothing worked anymore anyway.

## Run

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (242 characters,
one sentence, within the competition's 1–400 character gate).
